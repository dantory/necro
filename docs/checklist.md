# 새 요소를 넣을 때 반드시 지나는 것

병수님: *"이런거 하나하나 일일히 지적해줘야 하는게 진짜 지친다"*

지적받은 것들을 보면 **새로운 문제가 아니라, 이미 한 번 고친 것을 새 요소에 안 옮긴
것**이 대부분이었다. 캐릭터 접지를 고쳐 놓고 건물은 띄웠고, 던전 조명 순서를 잡아 놓고
마을은 조명 뒤에 그렸다. 그래서 **규칙을 여기 모아 둔다.** 화면에 무언가를 새로 넣을
때는 이 목록을 위에서 아래로 지난다.

## 그림을 화면에 놓을 때

- [ ] **접지** — `place()` 를 쓴다(js/ground.js). 이미지 바닥이 아니라 **알파 경계**가
      지면이다. PixelLab 그림은 아래에 투명 여백이 있어 그냥 놓으면 **둥둥 뜬다.**
- [ ] **그림자** — place() 가 함께 그린다. 발 폭에 맞추되 **큰 것일수록 비율을 줄인다.**
- [ ] **조명보다 먼저** 그린다. 나중에 그리면 어둠 위에 뜬 스티커가 된다.
      부르는 곳은 `drawGround` **하나뿐**이어야 한다(둘이면 순서도 둘이 된다).
- [ ] **톤 보정**을 지난다 — PixelLab 결과는 청회색으로 치우친다. 로더에서 sepia 를 섞는다.
- [ ] **정수 좌표**로 놓는다. 소수면 가장자리가 흐려진다.

## 장면(마을/던전)을 만들 때

- [ ] 그 장면의 **바닥**이 따로 있는가. 던전 돌바닥을 마을에 깔면 지하 창고가 된다.
- [ ] 그 장면의 **소품**이 따로 있는가. 관·뼈무더기가 굴러다니는 곳은 마을이 아니다.
- [ ] **경계를 그리지 않는다.** 벽·울타리는 곧 테두리다 — 맵은 끝이 없어야 한다.
- [ ] 사람이 있는 곳에는 **사람**이 있는가. 가게에 사람이 없으면 폐허다.
- [ ] **판(HUD)은 그대로 둔다.** 사라지면 다른 게임처럼 보인다.

## 애니메이션을 구울 때

- [ ] 템플릿(`walking-6-frames` 등)은 **맨몸 기준**이라 손에 든 것을 지운다.
      무기를 든 놈은 v3 로 굽고 「무기를 든 채」를 **말로 못박는다.**
- [ ] 프레임 수를 코드에 박지 않는다 — 종마다 다르다(`frameCount`).
- [ ] 타격은 **팔이 뻗는 칸**에서 터진다(`IMPACT_AT`). 시작과 동시에 터뜨리면
      원인보다 결과가 먼저 와서 「어색하다」가 된다.

## 스킬을 새로 넣을 때 (2026-08-15, 같은 지적을 두 번 받은 뒤)

- [ ] **벨트 아이콘**(`assets/ui/icon/<id>.png`) — 없으면 칸이 빈다. `icon_qa` 가 잡는다.
- [ ] **판에서 터지는 그림**(`assets/fx/…`) — **이건 자가 안 잡았다.** 그리는 쪽이 모르는
      kind 를 `hit`/`nova` 로 떨어뜨려서 **404 가 안 나고 남의 그림이 조용히 뜬다.**
      실제로 태우기는 소환 그림, 제물은 폭발 그림으로 나갔고, 저주는 **아무것도 안 떴다.**
      → `fx_art.mjs` 를 지난다. **두 스킬이 같은 파일을 쓰면 실패**다.
- [ ] **fx 를 하나라도 내는가.** 로그 한 줄로 끝나는 스킬은 화면에서 **안 쓴 것과 같다**.
- [ ] 새 kind 를 만들면 `FX_ART` 표에 한 줄 — 그리는 쪽에 `if (kind === …)` 로 흩지 않는다.
      흩으면 자가 「어느 그림을 쓰는지」를 물어볼 곳이 없어진다.

## UI 를 만들 때

- [ ] **디아블로는 목록이 아니라 격자와 툴팁이다.** 세로로 늘어선 표는 설정 화면이다.
- [ ] **등급은 색으로** 말한다(흰·파랑·노랑·금갈·초록). 이건 분위기가 아니라 **약속**이라
      예쁘게 바꾸면 못 알아본다.
- [ ] 값은 **지금 → 다음**으로. 얼마나 좋아지는지 안 보이면 고를 수가 없다.

## 검수할 때

- [ ] `Log.enable` 을 켠다 — 안 켜면 rAF 콜백 안의 예외를 **못 잡는다.**
- [ ] `Page.reload({ignoreCache:true})` — 안 하면 **ES 모듈이 옛 파일**로 남는다.
      오류 행 번호가 안 바뀌면 그 신호다.
- [ ] 좁은 폭(360)과 넓은 폭(1440) **둘 다** 본다.
- [ ] **상태를 믿지 말고 산출물로 판단한다** — 굽기 API 는 status: completed 여도
      다운로드가 423 일 수 있다.
- [ ] 편집 스크립트가 **저장 전에 죽지 않았는지** 본다(치환 실패는 조용하다).
