## 왜 헤맸는지 — 두 가지를 뒤섞었다
1. **레퍼런스를 둘 썼다.** UI 는 **히어로시즈**(좌상단 가로 바)를 뜯어 만들고, 판은 **D2** 를
   따라갔다. 병수님이 처음부터 말한 것은 **D2** 인데 UI 는 딴 게임 것이다.
   → `docs/HS_STYLE.md` 보다 **이 문서가 위**다.
2. **「안 가져온다」를 내가 정했다.** 아이소메트릭 시점과 「밖을 검정으로」를 둘 다
   「우리 작업을 지키려고」 접었다. 밖 검정은 병수님이 12:44 에 되돌리게 했다.
   **시점도 같은 자리에 있다.**

## 그래서 순서 (큰 것부터 · 잔손질 금지)
1. **UI 를 D2 결로** — 화면 아래 벨트, 좌우 구슬(체력 붉음 · 마나 푸름), 가운데 스킬 칸.
   **가장 크고, 시점을 안 바꾸고도 된다.** 지금 흩어진 셋을 한 덩어리로 모은다.
2. **톤을 어둡고 탁하게** — 바닥 밝기를 내리고 채도를 낮춘다. **화면에서 제일 밝은 것은
   불뿐**이어야 한다. 적 색조도 회색·핏빛으로 더 좁힌다.
3. **공간을 잇는다** — 방 하나 + 검정이 아니라, 큰 홀에 곁방이 붙고 아치가 이어지게.
4. **(별도 판단) 시점** — 아이소메트릭으로 가면 **에셋 여든 장을 다시 굽는다.** 큰일이라
   1~3 을 먼저 해서 얼마나 가까워지는지 보고 나서 정한다.
