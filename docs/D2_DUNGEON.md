# 디아블로 2 던전 문법 — 실제 도면에서 읽어 낸 것

병수님 2026-09-02 21:54: 「**디아블로2의 던전 스타일 참고 좀 해**」
참고 그림: `docs/ref/d2_catacombs.png` (카타콤 4층 전체 도면 · Diablo Wiki)
★ **에셋을 베끼지 않는다.** 「무엇이 던전을 던전으로 보이게 하는가」만 읽어 우리 결로 만든다.

## 한 장에서 읽히는 것 — 우리 판과 무엇이 다른가

| | D2 카타콤 | 우리 (hs/) |
| **벽** | **아치 열주가 벽면에 연속**으로 파여 있다. 벽이 두껍고 그 두께가 보인다 | **민 벽돌 면** — 무늬 한 겹 |
| **불** | **횃불·화톳불이 열댓 개.** 방마다 서넛씩, 벽에도 바닥에도 | 화로 두셋 |
| **바닥** | 어두운 회갈색 돌 + **핏자국·균열·잔해가 촘촘** | 균일한 색면, 자취가 성김 |
| **방 잇기** | 큰 홀에 **곁방이 ㄱ자로 붙는다.** 복도가 짧다 | 떨어진 사각형 + **긴 복도** |
| **랜드마크** | 붉은 제단(원형 핏자국) 같은 **큰 것 하나**가 방을 기억하게 만든다 | 방이 다 비슷 |
| **밖** | **완전한 검정.** 벽이 두꺼워 그것으로 충분하다 | 암반을 깔았다(V-212) — 이건 우리 쪽이 나을 수도 |

## 그래서 우리가 가져올 것 (순서대로)
1. **불을 열댓 개로.** 지금 화로 두셋은 너무 적다. **이것 하나로 「던전」이 반은 온다** —
   D2 도면에서 눈이 가장 먼저 붙는 것이 불이다. 벽 횃불 + 바닥 화톳불 둘 다.
2. **벽에 아치.** 민 벽돌 면이 창고로 읽히는 가장 큰 까닭. 벽면에 아치를 연속으로 파고
   그 안을 어둡게. (에셋 한 장이면 되고, 벽 무늬 위에 얹으면 된다.)
3. **바닥 자취를 촘촘히.** 핏자국·균열·부서진 것. 지금 밀도의 2~3배.
4. **방마다 랜드마크 하나.** 붉은 제단·부서진 관·뼈 무더기 — 방을 기억하게 만드는 큰 것.
5. ✔ **복도를 짧게, 방을 붙여서.** (V-263 `__ROOMSTIGHT` 닫음 2026-09-03) D2 는 큰 홀에 곁방이
   바로 붙는다. BSP 잎의 방을 형제 경계 쪽 벽에 붙이고, 마주 보고 가까운 두 방은 복도 대신
   짧은 목(문)으로 직결했다. 복도 총 길이 −29~36%·맞닿은 방 쌍 0→여럿·관통 0·도달 100%.
   ★ 다섯 항목 다 닫힘(①불 V-261 · ②아치 V-262 · ③바닥자취 V-261 · ④랜드마크 V-261 · ⑤방붙이기 V-263).
