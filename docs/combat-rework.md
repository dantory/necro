# 전투화면 재검토 (2026-08-10 밤)

병수님: "전투화면 처음부터 다시 재검토해서 제대로 만들어내라 밤새".
화면을 3배로 늘려 놓고 **눈으로 먼저** 뽑은 목록이다. 순서는 「없으면 게임이 안 읽히는 것」부터.

- [x] ① 아군과 적을 가른다 — 아군 발밑 룬, 체력바를 진짜 머리 위에 · 몸 폭으로
- [x] ② 시체를 판에 그린다 — 죽은 자리에 실물이 남고, 쓰면 그 자리 것이 사라진다
      (개수 S.corpses 와 그림 S.piles 는 addCorpse/useCorpse 두 길로만 움직인다)
- [x] ③ 죽는 순간 · 일어서는 순간 — 무너져 시체가 되고, 쓴 시체 자리에서 솟아오른다
- [x] ④ 맞은 티 — 떠오르는 피해 숫자(적 흰 · 내 편 주홍 · 본인 빨강·1.5배 · 회복 초록+ · 폭발 주황)와,
      때리는 놈→맞을 놈을 잇는 예고선(내 편 푸름 · 적 붉음 · 본인 겨눔은 가장 굵게). 본인이 맞는 것도
      pending 으로 옮겨 다른 모든 타격과 같은 칸에서 터진다(둘레 지난 적은 발밑도 붉게)
- [x] ⑤ 네크로멘서의 존재감 — 판의 주인공인데 제일 작고 어둡다. 발밑에 소환수 룬보다 큰
      **이중 소환진**을 깔고(바깥·안쪽이 경과 시간으로 반대로 도는 조각난 호 — 등속·RING_HOLD 안쪽),
      몸 뒤로 보랏빛 뒷광을 얹어 어두운 바닥과 가른다(실루엣은 안 건드린다). 크기 58→70 으로
      인간형 중 제일 크게. 시전(S.pswing)하면 소환진이 밝아지고 고리 하나가 바깥으로 퍼져 사라지고,
      체력 3할 아래면 소환진이 붉게 물들며 맥동이 빨라진다 — ④의 core 숫자는 맞는 순간만 뜨므로
      「지금 위태롭다」를 판에 상시로 남긴다(체력바는 HUD 에 이미 있어 머리 위엔 안 단다)
- [ ] ⑥ 층이 바뀌는 순간 · 관문에 들어서는 순간

## 하는 방법
`node tools/cdp_verify.mjs <out.png> ui` 로 예외·404·목록 어긋남을 재고,
`/tmp/nv_combat.mjs` 로 전투 화면을 여러 순간 찍어 **눈으로** 본다.
고칠 때마다 커밋하고 푸시한다(푸시하면 https://dantory.github.io/necro/ 에 그대로 간다).
