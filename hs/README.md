# hs/ — 핵앤슬래시 코어 프로토타입

D2 네크로멘서를 직접 몰고 넓은 던전을 돌아다니며 무리를 쓸어담고 쏟아지는 루팅을 파밍한다.
`http://127.0.0.1:8774/hs/index.html` 로 연다. 저장 없음 — 새로고침하면 처음부터.

**조작:** WASD/방향키 이동 · 마우스 좌클릭(누르고 있기) 뼈창 · Q 해골 소환 · E 시체 폭발 · F 계단으로 내려가기 · 죽으면 R.

**봐 달라:** ① 화면보다 훨씬 넓은 맵을 **돌아다니며** 흩어진 무리를 찾아 친다(가면 깨어나고, 방을 치면 조용해진다). ② 적이 죽으면 금과 물건이 **바닥에 이름표로 쏟아지고**, 밟으면 그 자리서 피해·몸 배수가 오른다(유니크는 화면이 번쩍이며 규칙이 바뀐다). ③ 우상단 **미니맵**으로 안 훑은 방·무리·상자·계단이 보인다 — 얼마나 파밍할지는 내가 정한다.
